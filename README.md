A tiny deterministic Node 22 program (stdlib only) that writes one original
joke about Monday mornings to `/output/entry.txt`.

The joke:

> My snooze button has worked so many Monday mornings, it unionized — and now it snoozes me.

Run it with:

```sh
node --experimental-strip-types main.ts
```

It always writes the same single line, well under the 200-character limit.
